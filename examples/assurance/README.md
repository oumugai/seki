# アシュアランスケースの例 — 温度制御ループ

`seki --audit examples/assurance` が、このディレクトリ全体について
**1枚の安全性論証**を出す。

安全性論証とは「証拠に支えられた構造化された議論」であり、そこに並ぶのは
必ず**証明・計算・仮定の混合**になる。全部証明するのは不可能で、全部を
テストで済ませるのは不誠実だからだ。seki はその混合を混合のまま扱い、
どの主張がどの等級の根拠に立っているかを機械が報告する。

## ファイルの役割

| ファイル | 何を主張するか | 根拠の種類 |
|---|---|---|
| `environment.seki` | 環境について仮定すること | 確度と出所つきの `axiom` |
| `sensor.seki` | センサ較正が仕様の範囲に収まる | 全入力についての証明 |
| `controller.seki` | 制御則がゲイン範囲全体で有界 | パラメータの箱についての証明 |
| `plant.seki` | 初期状態の**範囲全体**から収束する | 区間演算による到達可能性 |
| `system.seki` | 系全体の安全性 | 上の合成 |

## 読み方

レポートは「**カーネルの証明以外に立っている主張**」から始まる。
それが審査で実際に見る必要があるリストで、良い知らせの下に埋めない。
